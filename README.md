## Технологии

| Технология | Назначение |
|------------|------------|
| Python 3.14 | Язык программирования |
| Selenium WebDriver | Управление браузером |
| Pytest | Фреймворк для тестирования |
| Allure | Формирование отчетов |
| Page Object Model | Паттерн проектирования |
| Loguru | Логирование |

---

## Тест-кейсы

| № | Сценарий | Шаги | Ожидаемый результат |
|---|----------|------|---------------------|
| 1 | **Добавление в корзину** | Открыть каталог → выбрать диван → добавить в корзину → проверить корзину | Товар появился в корзине |
| 2 | **Добавление в избранное** | Открыть каталог → добавить товар в избранное → перейти в избранное | Товар отображается в избранном |
| 3 | **Фильтрация по цене** | Открыть каталог → применить фильтр цены (10 000–15 000 ₽) → проверить результаты | Отображаются товары в указанном диапазоне |
| 4 | **Детали товара** | Открыть каталог → перейти в карточку товара → проверить характеристики | Характеристики отображаются корректно |
| 5 | **Поиск по названию** | На главной странице ввести "Бостон" → нажать Enter → проверить первый результат | Первый товар содержит "Бостон" |

## Установка и запуск


1. Клонирование репозитория

```bash
git clone https://github.com/unpequenomilagro/mebelmart-autotest.git
cd mebelmart-autotest
```

2. Создание виртуального окружения

```bash
python -m venv venv
venv\Scripts\activate          # Windows
```

3. Установка зависимостей

```bash
pip install -r requirements.txt
```

4. Запуск тестов

```bash
pytest -v
```

5. Отчет

```bash
allure generate allure-results -o allure-report --clean
allure open allure-report
```
