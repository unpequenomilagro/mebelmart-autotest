# Mebelmart Autotest Framework

Фреймворк для автоматизированного тестирования GUI сайта Мебельмарт.

## Технологии
- Python 3.11+
- Selenium WebDriver
- Pytest
- Allure Reports
- Page Object Pattern
- Layered Architecture
